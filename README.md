# FTSynth
FTSynth is an instrument library of synthesizer ARPABET samples in the form of .fui files to import into [Furnace Tracker.](https://www.Tildearrow.org/furnace)
These .fui files work exactly as normal samples. to use them, you arrange the phonemes in a certain way inside of your pattern so replicate speech. Here is a demonstration of its current capabilities.
