# FTSynth
FTSynth is an instrument library of synthesizer ARPABET samples in the form of .fui files to import into [Furnace Tracker.](https://www.Tildearrow.org/furnace)
These .fui files work exactly as normal samples. to use them, you arrange the phonemes in a certain way inside of your pattern so replicate speech. To get the best results in chips like the NES (2a03,) make sure the PCM channel mode is set from DPCM to PCM. Here is a demonstration of its current capabilities (PCM mode on NES.)
